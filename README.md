# SISKA (Sistem Informasi Kepegawaian)
Aplikasi manajemen data pegawai berbasis web yang dibangun menggunakan framework Laravel. Aplikasi ini dirancang untuk memudahkan instansi/perusahaan dalam mengelola data kepegawaian secara terpusat, cepat, dan terstruktur.

## 🚀 Fitur Utama
- **Dashboard Eksekutif:** Menampilkan statistik total pegawai, pegawai aktif, pendidikan terbanyak, serta visualisasi grafik (Gender, Status, Pendidikan, dan Usia).
- **Manajemen Pegawai (CRUD):** Tambah, Edit, dan Hapus data pegawai dalam satu halaman (Single Page Form).
- **Pencarian & Multi-Filter:** Filter data berdasarkan Nama, Pendidikan, Gender, dan Status.
- **Validasi Form:** Validasi input server-side menggunakan bawaan Laravel.
- **Desain Responsif:** Antarmuka modern menggunakan Bootstrap 5 dan animasi Sidebar yang bisa di-minimize.

## 🛠️ Teknologi yang Digunakan
- **Backend:** Laravel (PHP 8+)
- **Frontend:** Bootstrap 5.3.3, Bootstrap Icons, Chart.js
- **Database:** MySQL
- **Tools:** Visual Studio Code, MySQL Workbench
